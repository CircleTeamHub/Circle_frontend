# 开发与预发邮箱验证码

配套后端：CircleTeamHub/circle_be#303。当前 App 的邮箱验证码入口是忘记密码及邮箱恢复流程；注册不再发送验证码，普通登录使用密码。前端始终向后端提交验证码，由后端判断是否有效。

开发环境显式配置：

```dotenv
NODE_ENV=development
EMAIL_CODE_DEV_BYPASS=999999
```

隔离的预发环境使用生产构建，并显式配置部署阶段：

```dotenv
NODE_ENV=production
APP_DEPLOY_ENV=preproduction
EMAIL_CODE_DEV_BYPASS=999999
```

部署阶段默认是 `production`。真实生产环境不会把 `999999` 当作万能验证码；正常发送的随机验证码仍按原流程验证。固定码未配置、为空或为 `off` 时不启用，错误的部署阶段会导致启动校验失败。

在开发或隔离预发中，用已有测试账号打开忘记密码，直接提交 `999999` 和新密码即可，无需先发送邮件。发送邮件按钮仍要求正确配置 SMTP，未配置时仍返回不可用错误。

此配置不改变受信任设备批准码、登录安全码或密保答案验证。合并 PR 不会自动部署后端或修改服务器环境变量。
