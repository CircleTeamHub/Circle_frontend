# WindNote 测试缺口审计

本分支补齐了跨平台 Maestro 核心旅程、Socket.IO/REST 并发负载、Android/iOS UI 性能采集和 CI 快速契约，但以下内容仍需要后续独立工作或真实环境验证。

| 优先级 | 缺口 | 建议验证 |
| --- | --- | --- |
| P0 | 真机发布包尚未运行本套流程 | 至少一台低端 Android、一台主流 Android、一台较旧 iPhone 与当前 iPhone；release-like build 全套六条 E2E |
| P0 | 推送端到端 | 前后台/被杀、通知点击路由、免打扰、token 轮换、重复通知、隐私内容隐藏 |
| P0 | 弱网与断线重连 | 丢包、延迟、断网、切 Wi-Fi/蜂窝、token 刷新期间发送、乱序广播与幂等重试 |
| P0 | 服务端容量基线尚未实跑 | 从 1→10→50→100 VU ramp，关联 API、Socket、数据库、队列与告警 |
| P1 | 大媒体聊天 | 多图、长视频、语音、下载取消、缓存上限和 OOM；与默认轻量文本场景分开 |
| P1 | 音视频通话 | 多设备来电、拒接/超时、前后台、权限拒绝、音频路由、LiveKit 重连和资源释放 |
| P1 | 数据迁移与升级 | 旧版本 MMKV/SQLite 到新版本、账号切换、登出清理、损坏缓存恢复 |
| P1 | 上传/发布部分失败 | presign 过期、上传中断、重复提交、动态发布成功但附件失败、恢复与清理 |
| P1 | 长时稳定性 | 2-8 小时 soak、频繁前后台、事件风暴、监听器/定时器泄漏和内存缓慢增长 |
| P2 | 可访问性与多语言视觉回归 | VoiceOver/TalkBack、字体放大、触控目标、深色模式、小屏、长文案和 RTL 评估 |
| P2 | 安全动态测试 | deeplink/QR/WebView/上传恶意输入、证书/传输、日志与 Sentry PII 扫描 |

设备测试完成前，CI 只运行无凭证、无网络、无需模拟器的契约测试，避免把环境偶发故障变成合并噪音。真机、负载和长时测试应由受控 nightly/release workflow 执行并保存原始 artifacts。
