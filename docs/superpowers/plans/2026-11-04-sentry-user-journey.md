# Sentry 用户与操作路径关联

用户明确要求允许把内部用户 ID 发往 Sentry，覆盖此前完全匿名的用户关联策略；其余身份字段、业务内容及指标标签的隐私边界保留。

- [x] SDK 用户 scope 及最终事件过滤只保留 `user.id`，支持按内部用户 ID 搜索。
- [x] 登录/退出/切换账号同步更新身份，清空旧账号诊断与页面历史；延迟发送的旧事件不混入新账号记录。
- [x] 保存最近 20 次归一化页面跳转，独立于接口诊断缓冲，错误附带快照。
- [x] 回归覆盖手动/自动异常、事务、切号、退出、历史上限、脱敏和旧会话异步失败。
- [x] 说明前端 Sentry 看板、查询方法与新包生效条件。

复用现有 Sentry、导航及诊断模块，不新增采集 SDK，不把用户 ID 放入 Prometheus/Sentry 指标标签，不开启录屏或文本采集。

验证：全量 Node 测试 3555 通过、30 跳过、0 失败；登录与收藏行为测试 39 通过；typecheck、lint、diff 检查通过。当前新增换邮箱/注销路由及换邮箱接口也已补入监控模板。

安装新包后的 Sentry 到达、用户搜索、真实设备操作路径及同构建 source maps 仍需上线验收；本轮未发布 App，也未新建远程前端 Dashboard。
